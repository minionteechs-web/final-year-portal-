# UNN Computer Science — Formatting & Page Budget

Official CS constraints used for this project:

| Setting | Value |
|---------|--------|
| Paper | A4 |
| Font | Times New Roman |
| Body size | **14 pt** |
| Line spacing | **1.5** |
| Margins | **1 inch** on all sides |
| Alignment | Justified |
| Full report ceiling | **≤ 60 pages** (including source-code listing) |
| Proposal / Ch 1–3 pack | **20–30 pages** (prelims + Ch 1–3) |

## Chapter targets (UNN CS)

| Part | Pages |
|------|-------|
| Preliminary pages | ~6–8 (Roman *i, ii, iii…*) |
| Chapter 1 | 4–6 |
| Chapter 2 | 8–12 |
| Chapter 3 | 8–12 |
| **Prelims + Ch 1–3** | **≤ 30** |
| Chapter 4–5 + refs + code listing | fit remaining to **≤ 60** total |

Page numbers: Arabic **1, 2, 3…** start at Chapter One (bottom centre). Prelims use Roman numerals; title page may omit a visible number.
